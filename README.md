# Миксбордер «Розовый сад»

Дизайн-проект клумбы 4,8 × 1,8 м: посадочный чертёж, календарь цветения и спецификация растений.

- **Живая страница:** https://smmakschcg.github.io/rozovy-sad/
- **Репозиторий:** https://github.com/SmMaksCHCG/rozovy-sad

## Состав

Семь видов из задания:

- 2 куста пиона (`Sarah Bernhardt`, `Festiva Maxima`)
- 3 лилии (OT-гибриды `Star Gazer` и `Casa Blanca`)
- флокс метельчатый `Bright Eyes`
- лаванда узколистная `Hidcote`
- гладиолусы, лососево-малиновая смесь
- анютины глазки `Matrix`
- низкая гвоздика перистая `Pink Jewel`

Три новых вида, чтобы закрыть июльскую паузу после пионов:

- шалфей дубравный `Caradonna`
- эхинацея пурпурная `Magnus`
- котовник Фассена `Walker’s Low`

## Запуск локально

```bash
npm install
node scripts/ensure-images.mjs
npm run dev
```

Приложение откроется на [http://localhost:4521](http://localhost:4521).

Сборка статического сайта:

```bash
npm run build
```

Каталог `out/` можно выложить на любой статический хостинг.

## Как пользоваться

- На чертеже сверху клик по кругу растения открывает карточку сорта и шага посадки.
- Фильтр по месяцам показывает, что цветёт в выбранный срок.
- Карточки каталога прокручивают обратно к плану и подсвечивают вид.
